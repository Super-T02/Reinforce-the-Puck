\subsection{New Replay Buffers\protect\footnote{Implemented and written by Tom Freudenmann}} \label{sec:buffers}

The basic approach for modelling experience buffers are \ac{ER} buffers \cite{lin1992ER}, which hold the past $n$ (most of the time $n>100000$) transitions and at training time $m$ transitions are sampled as batch to train actor and critic networks. Although, the  sampling is done at each iteration uniformly, early observations in the empty buffer  are sampled more often than late experiences, which describe the current learning state \cite{schaul2015prioritized}. To overcome this issue, we propose first \ac{BER},  \ac{PER} \cite{schaul2015prioritized} and \ac{BPER}.

\paragraph{\acl{BER}} \ac{BER} is a balanced version of the default \ac{ER} where each experience gets a corresponding memory strength. This strength is reduced every time a new experience is added to the  buffer. The resulting probability to draw an experience $j$ from the buffer is $P(j) = \frac{s_j^\alpha}{\sum_{i}s_i^\alpha}$, where $s_i$ corresponds to the strength of experience $i$.

\paragraph{\acl{PER}} \ac{PER} is introduced by \cite{schaul2015prioritized} and focuses on prioritizing experiences with an big \ac{TD}-error. Thus, each experience $j$ has a sampling probability $P(j) = \frac{\delta_j^\alpha}{\sum_{i}\delta_i^\alpha}$, where $\delta_i$ is the \ac{TD}-error of experience $i$ and $\alpha$ is an hyperparameter describing the influence of the priorities. In general, each metric can be used to assign priorities but may lead to a bias towards the sampled data. To further balance the sampling we implement the buffer as SumTrees, which allow sampling and adding data in $O(log\,n)$ and is proposed by \cite{schaul2015prioritized} for more efficient buffers.

\paragraph{\acl{BPER}} \ac{BPER} is a combination of balancing the probability by the memory strength and assigning a priority to the experience. Therefore, we use effective priorities $e_i = p^\alpha_i \cdot s_i$, where $p_i$ is the priority and $s_i$ the memory strength of sample $i$. These effective priorities are then translated into the sampling probability. Furthermore, we use as $p_i$ the normalized reward $r_i' = \frac{r_i - \min_j r_j}{\max_j r_j - \min_j r_j}$, because we want experiences with highest rewards, which introduces a bias towards experiences with high reward. After sampling the experiences, the old rewards of the sampled data are updated with the new rewards.
